# Deliverables

This folder contains the submission artifacts mapped to the PMA.pdf requirements.

## Included Files

- `deliverables/weekly_deployment_update.json` — n8n workflow export (runnable).
- `deliverables/implementation-writeup.md` — 1-page write-up with definitions, classification, edge cases, and assumptions.
- `deliverables/confluence_week-03.md` — Confluence output proof.
- `deliverables/slides_week-2026-W03.txt` — Slide output proof (text format).
- `deliverables/verification_summary_2026-W03.md` — Quick verification summary.
- `deliverables/run_index.csv` — Run history with output paths.
